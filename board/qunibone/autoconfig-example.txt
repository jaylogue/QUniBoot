# QUniBoot Auto-configuration Settings File
#
# Use this file to automatically configure a QUniBoot system when the 
# system boots. Auto-configuration can be used to configure a newly
# installed system image, or reconfigure an existing system.
#
# To enable auto-configuration:
#
# 1. Insert the SD card into your computer and wait for the BOOT drive
#    to appear.
# 
#    NOTE: If you just installed a new QUniBoot image on the card, you may
#    need to remove and re-insert it in order to get the BOOT drive to appear.
# 
# 2. Open the BOOT drive and copy the autoconfig-example.txt file to a
#    new file called autoconfig.txt.
# 
# 3. Open the autoconfig.txt file with a text editor. Uncomment (remove
#    the #) and fill in the settings with appropriate values for your system.
#    Follow the descriptions below to understand the purpose and syntax
#    of each setting.
# 
#    Note that it is not necessary to provide values for every setting. Any
#    value not set will leave the existing/default configuration in place.
#       
#    Indeed, on a new system, it is not necessary to change any of the
#    system settings, as the default values are entirely sufficient to use
#    the system. However, for security reasons, it is strongly encouraged
#    to set at least one of the following values:
#    
#    - ROOT_PASSWORD -- Set the root user password
#    
#    - ROOT_AUTHORIZED_KEY -- Set an authorized SSH key for the root user
# 
# 4. When done editing, close the file and safely eject the SD card.
# 
# 5. Insert the card into the UniBone/QBone and boot the PDP-11 system.
# 
# If auto-configuration is successful, the system will flash the UniBone/QBone
# LEDs 3 times. If an error occurs, the system will light the LEDs and leave
# them on. After a failure, the system log file (/var/log/messages) can be
# inspected to determine the cause.
# 
# Once auto-configuration completes, the system will rename the autoconfig.txt
# file to autoconfig-completed.txt to ensure it doesn't get re-applied at the
# next boot.
# 

# Set the system hostname
#
#HOSTNAME=<string>

# Configure the system to use a static IPv4 address, netmask, gateway
# and DNS server.
#
# Note that CIDR notation (e.g. XXX.XXX.XXX.XXX/24) CANNOT be used in
# the IP_ADDR setting. Use netmask instead.
#
#IP_ADDR=<XXX.XXX.XXX.XXX>
#NETMASK=<XXX.XXX.XXX.XXX>
#GATEWAY=<XXX.XXX.XXX.XXX>
#NAMESERVER=<XXX.XXX.XXX.XXX>

# Configure the system to use DHCP to acquire network configuration.
#
# This is the default for a newly-installed system. However, enabling
# this line will reset an existing system back to using DHCP.
#
#IP_ADDR=DHCP

# Set the password for the root user.
#
#ROOT_PASSWORD=<string>

# Add the given SSH public key to the root user's authorized_keys file
#
# The value should be the base64 encoded public key in standard authorized_keys
# format (e.g. "ssh-rsa AAA....").
#
# This setting has no effect if the key already exists in root's
# authorized_keys file.
#
#ROOT_AUTHORIZED_KEY=<base64-pub-key>

# Clear (delete) the root user's authorized_keys file
#
# This can be used with the ROOT_AUTHORIZED_KEY setting to entirely
# replace the root user's authorized_keys file.
#
#ROOT_AUTHORIZED_KEY=CLEAR

# Install SSH host key files
#
# Key files must be located in the same directory as the autoconfig.txt
# file and should be named ssh_host_*_key and ssh_host_*_key.pub (e.g.
# ssh_host_rsa_key, ssh_host_rsa_key.pub). Existing key files on the
# system, if any, are preserved as .orig files.
#
# This setting has no effect if the contents of the new files are the same
# as the files already installed on the system.
#
#INSTALL_HOST_KEYS=TRUE
